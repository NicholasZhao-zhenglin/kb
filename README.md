# 个人知识库

零依赖**单文件**知识库网页。`index.html` 就是全部 —— 拷到任何地方双击即用，断网可读，无 CDN、无构建、无框架。

**在线版**：<https://nicholaszhao-zhenglin.github.io/kb/>

原文逐字保留，未改写只重排：条目标题独占 `h1`，原文的「部分 / 章 / 小节 / 小点」依次落到 `h2 / h3 / h4 / h5`。

## 功能

- **全文检索**：标题 / 标签 / 正文，结果带上下文片段与高亮。`/` 或 `⌘K` 聚焦，`↑↓` 选，`Enter` 打开
- **章节目录**：左栏由正文标题现生成，滚动跟随高亮；点目录做页内跳转，不触发路由
- **收藏 / 最近阅读**：写在浏览器 `localStorage`，不上传不联网
- **深浅主题 / 4 档字号 / 代码块一键复制 / 表格窄屏横滑**
- **导入导出 JSON**：把外部条目追加进本地，或备份后换设备
- **打印样式**：`⌘P` 直接出干净的 PDF

## 改内容

**最快**：侧栏「导入 JSON」→ 选一个 JSON，条目进浏览器本地存储。
格式见「导出备份」出来的文件：`{ "arts": [ { id, cat, title, summary, tags, html, outline } ] }`。

**进内置内容**：编辑 `build.py` 的 `ARTICLES`（或 `append_article.py` 的 `SPEC` + `src/`），重跑：

```bash
python3 build.py           # 或 python3 append_article.py
```

生成器会自己跑一遍断言（锚点唯一、目录锚点不悬空、标题层级、表格容器闭合、零外部依赖、数据块 JSON 可解析），
不通过直接报错退出。`build.py` 的 `DEFAULT_SRC` 指向本地手册路径，换环境需要改这一行。

## 验证

```bash
# 1) 逻辑：jsdom 里真跑页面脚本
NODE_PATH=<node_modules> node verify.js

# 2) 渲染：驱动本机 Chrome（走 CDP，零 npm 依赖），并出图到 shots/
node cdp-verify.js
```

两个脚本都是**红绿判据**，失败退出码 1。断言写成「UI 忠实反映数据」的结构性不变量
（如「首页卡片数 = 分类数 + 条目数」），而不是硬编码某个时期的绝对数字，内容增长也不会假失败。

## 设计取舍

- **单文件而不是多文件**：`file://` 下 `fetch` 本地文件会被浏览器拦，内容必须内联；顺带的好处是归档不会散。
- **目录现生成而不是抄原文**：少一处要同步维护的重复清单，也就没有「两份目录对不上」的问题。
- **目录锚点不走 `#` 路由**：路由占用 `#/...`，页内锚点必须 `preventDefault` 手动 `scrollIntoView`，否则点目录会被当成换页。
- **标题整体降一级**：条目标题独占 `h1`。降级顺序必须先把 `h4` 挪到临时标签，再降 `h3`，最后落 `h4`
  —— 写成「先 h4→h3、再 h3→h2」会把刚降下来的又降一次，全篇小标题塌成一级。
